# Ballkartenverkauf Feuerwehr Pyhra – Web-App (Schritt 2)

React + Vite + Tailwind CSS + Leaflet (OpenStreetMap) + Supabase.

## Start
1. `sql/schritt2_ergaenzung.sql` im Supabase SQL-Editor ausführen.
2. Datei `.env.example` kopieren zu `.env` und die Supabase-Werte eintragen.
3. `npm install` und danach `npm run dev`.

Nur den öffentlichen anon/publishable Key verwenden, niemals den service_role Key.
